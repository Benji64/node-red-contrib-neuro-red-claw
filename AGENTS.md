# Instructions pour l'agent

- Suis les instructions et objectifs déjà définis dans le projet.
- Décompose les travaux en petites étapes et enchaîne-les sans demander une confirmation entre chaque étape.
- Après chaque modification, vérifie le résultat et lance les tests pertinents.
- En cas d'erreur, analyse-la, corrige-la et relance les vérifications.
- Si une étape est bloquée, explique précisément ce qui manque et poursuis les autres tâches indépendantes.
- Ne déclare pas une tâche terminée sans avoir vérifié le résultat.
- Demande mon accord avant les opérations destructrices, les suppressions importantes, les déploiements, les dépenses ou les changements de sécurité.
- À la fin, résume les modifications, les tests exécutés et les éventuels points bloquants.
